# Proyecto mi bici documentation!

## Description

Manuel Díaz BorregoEl dataset abierto de MiBici, sistema de bicicletas públicas del Área Metropolitana de Guadalajara, proporciona información histórica sobre el uso del servicio desde diciembre de 2014 hasta septiembre de 2026, con más de 39 millones de viajes registrados. Los datos están disponibles en archivos CSV organizados por mes y año, permitiendo analizar patrones de movilidad urbana, estaciones de origen y destino, horarios de mayor demanda y tendencias temporales. Este conjunto de datos representa una excelente oportunidad para desarrollar un proyecto de Machine Learning (ML) utilizando la metodología MLOps, donde podrán implementar modelos de predicción de demanda, identificar patrones de movilidad, detectar anomalías y estimar necesidades de redistribución de bicicletas etc. El proyecto permitirá trabajar con datos reales y aplicar prácticas de ingeniería de datos, versionamiento de datasets, entrenamiento y evaluación de modelos, automatización de pipelines, despliegue y monitoreo del desempeño de modelos de ML a lo largo del tiempo.
